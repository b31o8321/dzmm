# v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the GM-output robustness gap exposed by real-Ollama smoke testing, finish CRUD (edit/delete), and ship a real native desktop app via PyInstaller sidecar.

**Architecture changes (over v0.1):**
1. Backend's `service/game.py` gains a **graceful degradation** path: if the GM stream finishes with zero `<narrative>` tags emitted, treat the captured raw text as narrative and emit it as one final `NarrativeDelta`. Avoids the empty-screen bug seen with reasoning models like deepseek-r1.
2. GM prompt template gets a **format compliance reinforcement** at the very end (last system-message line is the strongest priming point).
3. Backend gains `PUT/DELETE` routes on `/worlds`, `/characters`, `/model_configs`. Cascade rules: deleting a world refuses if characters/sessions reference it; deleting a character refuses if sessions reference it; deleting a model_config refuses if sessions reference it.
4. Frontend tables get inline edit + delete buttons + confirmation dialog.
5. Backend gets a **PyInstaller spec** that produces a single `dzmm-backend` binary. Tauri's `tauri.conf.json` declares it as `externalBin`. Tauri's Rust shell spawns it on startup, kills it on close. Frontend client picks `127.0.0.1:8765` in non-dev (already done in v0.1, no change needed).

**Tech additions:** PyInstaller, Tauri sidecar API.

async def delete_world(world_id: int, s: AsyncSession = Depends(get_session_dep)):
    w = await s.get(World, world_id)
    if w is None:
        raise HTTPException(404, "world not found")
    has_chars = (
        await s.execute(
            select(CharacterModel.id).where(CharacterModel.world_id == world_id).limit(1)
        )
    ).scalar_one_or_none()
    if has_chars is not None:
        raise HTTPException(409, "world has characters, delete them first (该世界仍有角色)")
    has_sessions = (
        await s.execute(
            select(SessionModel.id).where(SessionModel.world_id == world_id).limit(1)
        )
    ).scalar_one_or_none()
    if has_sessions is not None:
        raise HTTPException(409, "world has sessions (该世界仍有跑团存档)")

import { defineStore } from 'pinia'
import { ref } from 'vue'
import type { World, WorldIn } from '@/api/types'
import { worldsApi } from '@/api/worlds'

export const useWorldsStore = defineStore('worlds', () => {
  const items = ref<World[]>([])
  const loading = ref(false)

  async function refresh() {
    loading.value = true
    try {
      items.value = await worldsApi.list()
    } finally {
      loading.value = false
    }
  }

  async function create(body: WorldIn) {
    const w = await worldsApi.create(body)
    items.value.push(w)
    return w
  }

  async function update(id: number, body: WorldIn) {
    const w = await worldsApi.update(id, body)
    const idx = items.value.findIndex((x) => x.id === id)
    if (idx >= 0) items.value[idx] = w
    return w
  }

  async function remove(id: number) {
    await worldsApi.remove(id)
    items.value = items.value.filter((x) => x.id !== id)
  }

  return { items, loading, refresh, create, update, remove }
})

"""PyInstaller entrypoint. Starts uvicorn synchronously."""
import asyncio
import os
import sys

import uvicorn

from dzmm.main import build_default_app


def main():
    port = int(os.environ.get('DZMM_PORT', '8765'))
    host = os.environ.get('DZMM_HOST', '127.0.0.1')

    async def run():
        app = await build_default_app()
        config = uvicorn.Config(app, host=host, port=port, log_level='info')
        server = uvicorn.Server(config)
        await server.serve()

    asyncio.run(run())


if __name__ == '__main__':
    sys.exit(main() or 0)

- [ ] **Step 9: Modify `frontend/src-tauri/src/lib.rs` to spawn the sidecar**

Replace the file contents with:

```rust
use tauri::Manager;
use tauri_plugin_shell::ShellExt;
use tauri_plugin_shell::process::CommandEvent;

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .setup(|app| {
            let sidecar = app.shell().sidecar("dzmm-backend")
                .expect("failed to resolve dzmm-backend sidecar");
            let (mut rx, _child) = sidecar.spawn()
                .expect("failed to spawn dzmm-backend");

            tauri::async_runtime::spawn(async move {
                while let Some(event) = rx.recv().await {
                    if let CommandEvent::Stdout(line) = event {
                        let s = String::from_utf8_lossy(&line);
                        eprintln!("[dzmm-backend] {}", s.trim_end());
                    } else if let CommandEvent::Stderr(line) = event {
                        let s = String::from_utf8_lossy(&line);
                        eprintln!("[dzmm-backend ERR] {}", s.trim_end());
                    }
                }
            });
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```
