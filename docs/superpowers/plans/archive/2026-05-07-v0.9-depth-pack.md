# v0.9 Depth Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every dice check a vivid little scene (animation + sensory description + NPC reaction), pace the rest of the narrative tighter to compensate; aggregate combat dice into a single CombatPanel; give NPCs persistent vector memory; introduce a faction/reputation system; surface a history-events timeline.

**Architecture:** Extend `<dice>` parsing to accept nested `<scene>` and `<reaction>` children — the LLM emits all three in one pass, no extra round trip. Frontend renders dice as a 3-section card (mechanics / scene / reactions) with stage-sequenced animations. Combat is just a connected sequence of `category="combat"` dice contained in a CombatPanel that aggregates HP and turn order. NPC memory uses ChromaDB (already in deps for v0.4 RAG) with one collection per NPC; summarized after each `<say>` and retrieved before each NPC's turn. Factions are a new lightweight table with hostile/allied edges and PC reputation; GM emits faction events that adjust state. Timeline is a StatePanel drawer reusing existing plot_event data.

**Tech Stack:** Vue 3 + TypeScript + Element Plus + Tailwind (frontend); FastAPI + SQLAlchemy + SQLite + ChromaDB (backend). Lottie for d20 animation; existing TTS / asset infrastructure from v0.7 / v0.8.

**Depends on:** v0.8 (asset system — used to host the 28 dice sfx in `packaging/assets/builtin/audio/sfx/dice/`).

- [ ] **Step 2: Parse nested children inside `<dice>`**

In `stream_parser.py`, locate the dice tag handling. When `<dice>` open is detected, capture content until `</dice>`. Within that content:

```python
import re

_SCENE_RE = re.compile(r"<scene>([\s\S]*?)</scene>", re.IGNORECASE)
_REACTION_RE = re.compile(
    r"<reaction\s+([^>]*?)>([\s\S]*?)</reaction>",
    re.IGNORECASE,
)
_SPEAKER_ATTR_RE = re.compile(r'speaker="([^"]*)"')
_MOOD_ATTR_RE = re.compile(r'mood="([^"]*)"')


def _parse_dice_inner(content: str, dice: DiceTag) -> None:
    scene_match = _SCENE_RE.search(content)
    if scene_match:
        dice.scene_text = scene_match.group(1).strip()
    for rm in _REACTION_RE.finditer(content):
        attrs = rm.group(1)
        sp_m = _SPEAKER_ATTR_RE.search(attrs)
        md_m = _MOOD_ATTR_RE.search(attrs)
        dice.reactions.append(DiceReaction(
            speaker=sp_m.group(1) if sp_m else "",
            mood=md_m.group(1) if md_m else "",
            text=rm.group(2).strip(),
        ))
    # Backward compat: if no <scene>, treat entire content as legacy description
    stripped = content.strip()
    if not dice.scene_text and not dice.reactions:
        # remove any leftover XML-ish noise; keep plain text
        dice.description = re.sub(r"<[^>]+>", "", stripped).strip()
    elif not dice.description:
        dice.description = dice.scene_text[:120]  # for events_json compactness
```

In the dice-close handler, call `_parse_dice_inner(captured_content, dice_tag)` before yielding the tag.

```
## 铁律 N：dice 检定必须详写（v0.9）
每个 `<dice>` 必须含 `<scene>` 子标签（2-4 句感官细节：视觉/听觉/嗅觉/触觉/心理）。
至少 1 个相关 NPC 在场时，至少 1 条 `<reaction speaker="..." mood="...">` 子标签；
mood 是该 NPC 此时的情绪状态（如「无察觉/警觉/愤怒/惊讶/嘲讽/恐惧/敬佩」等）。

dice 是叙事密度的**峰值**：普通 narrative 可以白描快推进，dice 必须「慢镜头」。

## 铁律 N+1：节奏倾斜
- 非 dice 回合：narrative 简洁，2-4 句推进剧情即可，避免过度堆描写
- dice 回合：narrative 主体可短，但 `<scene>` 内必须感官化、具体化
- **不要每段 narrative 都堆细节**；好节奏是「快进 + 关键定格」交替
- 战斗 / 对话 / 调查 / 潜行 等任何检定都适用，不只限战斗

## <dice> category 取值（必填，v0.9）
- combat：攻击 / 防御 / 武技
- stealth：潜行 / 偷窃 / 隐匿
- persuasion：说服 / 欺骗 / 威吓 / 谈判
- arcane：法术 / 仪式 / 神秘学
- athletics：攀爬 / 跳跃 / 翻越 / 力量
- perception：观察 / 搜寻 / 直觉 / 警觉
- knowledge：学识 / 推理 / 记忆 / 鉴定
- generic：兜底（尽量避免使用，分类越准玩家体验越好）
```

- [ ] **Step 2: useDiceAnimation composable**

```typescript
import { ref, onMounted } from 'vue'

interface Stage {
  rolling: boolean
  resultShown: boolean
  sceneShown: boolean
  reactionsShown: number   // index of last visible reaction
}

export function useDiceAnimation(numReactions: number, autoPlay = true) {
  const stage = ref<Stage>({
    rolling: false, resultShown: false, sceneShown: false, reactionsShown: 0,
  })

  function play() {
    stage.value = { rolling: true, resultShown: false, sceneShown: false, reactionsShown: 0 }
    setTimeout(() => { stage.value.rolling = false; stage.value.resultShown = true }, 800)
    setTimeout(() => { stage.value.sceneShown = true }, 1100)
    for (let i = 0; i < numReactions; i++) {
      setTimeout(() => { stage.value.reactionsShown = i + 1 }, 1500 + i * 600)
    }
  }

  onMounted(() => { if (autoPlay) play() })
  return { stage, play }
}
```

```python
"""Per-NPC long-term memory backed by ChromaDB. Each NPC gets one collection
(`npc_mem_{npc_id}`); each `<say>` triggers a one-line summary by the
summarizer model and an upsert into the NPC's collection. Before the GM
takes a turn, retrieve top-k memories for each on-stage NPC and inject."""
from __future__ import annotations

import logging
from pathlib import Path

from sqlalchemy.ext.asyncio import AsyncSession

from dzmm.db.models import NPC
from dzmm.models.client import GenerationParams, Message, ModelClient
from dzmm.service.world_rag import OllamaEmbedder  # reuse v0.4 embedder

log = logging.getLogger(__name__)

_TOP_K = 3
_APP_DIR: Path | None = None


def init_app_dir(app_dir: Path) -> None:
    global _APP_DIR
    _APP_DIR = app_dir


def _coll_name(npc_id: int) -> str:
    return f"npc_mem_{npc_id}"


def _client():
    import chromadb
    assert _APP_DIR is not None
    return chromadb.PersistentClient(path=str(_APP_DIR / "chroma_npc"))


async def record_memory(
    npc_id: int,
    turn: int,
    text: str,
    summarizer: ModelClient | None = None,
    ollama_url: str = "",
) -> None:
    """Record a single memory line for npc_id at turn N. If summarizer is
    provided, condense `text` into a 1-sentence memory; else store raw."""
    if not text.strip() or not _APP_DIR or not ollama_url:
        return

    summary = text.strip()[:300]
    if summarizer is not None:
        try:
            messages = [
                Message(role="system", content="将下列对话浓缩成 1 句不超过 60 字的中文记忆，作为 NPC 的私人记忆。仅输出这句记忆，不要解释。"),
                Message(role="user", content=text[:600]),
            ]
            chunks = []
            async for c in summarizer.stream(messages, GenerationParams(max_tokens=80, temperature=0.3)):
                if c.delta:
                    chunks.append(c.delta)
            condensed = "".join(chunks).strip()
            if condensed and 5 < len(condensed) < 200:
                summary = condensed
        except Exception as e:  # noqa: BLE001
            log.debug("npc_memory: summarizer failed (%s) — using raw", e)

    try:
        embedder = OllamaEmbedder(ollama_url=ollama_url)
        emb = (await embedder.aembed_documents([summary]))[0]
        coll = _client().get_or_create_collection(_coll_name(npc_id))
        coll.add(
            ids=[f"t{turn}_{coll.count()}"],
            documents=[summary],
            embeddings=[emb],
            metadatas=[{"turn": turn}],
        )
    except Exception as e:  # noqa: BLE001
        log.warning("npc_memory: record failed for npc %d: %s", npc_id, e)


async def retrieve_memories(
    npc_id: int,
    query: str,
    ollama_url: str = "",
    k: int = _TOP_K,
) -> list[str]:
    if not query.strip() or not _APP_DIR or not ollama_url:
        return []
    try:
        embedder = OllamaEmbedder(ollama_url=ollama_url)
        q_emb = (await embedder.aembed_documents([query]))[0]
        coll = _client().get_or_create_collection(_coll_name(npc_id))
        if coll.count() == 0:
            return []
        result = coll.query(query_embeddings=[q_emb], n_results=min(k, coll.count()))
        return result["documents"][0] if result.get("documents") else []
    except Exception as e:  # noqa: BLE001
        log.warning("npc_memory: retrieve failed for npc %d: %s", npc_id, e)
        return []
```

```python
    name = (attrs.get("name") or "").strip()
```
