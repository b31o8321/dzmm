# 长线路线图（v0.8 → v1.0）

主线索：**让世界有记忆，让人物有目的，让玩家少踩坑。**

---

## v0.8（当前）— 编年史 + 目标 + 易用性

**主题：** 让玩过的剧情可追溯，让 PC 有自己的目标，让新用户进得来。

详细见 [v0.8 计划](2026-04-29-v0.8.md)。

- 编年史页（Timeline UI + Era 分章）
- PC 目标列表（GM 用 `<pc_goal>` 自动登记）
- 首次启动引导（4 步教程 + WelcomeView）
- Tauri 自动更新（GitHub Releases 推送）

---

## v0.9 — 情绪系统 + GM 反应性

**主题：** 让 NPC 真的"在乎"你做的事，让世界对你的状态有反应。

### Task 列表

1. **NPC 情绪模型** — `NPC.emotion_json = {anger, love, fear, respect, jealousy}`，每项 0-100
   - GM 用扩展的 `<npc_update>` 推送：`"emotion": {"anger": +10, "fear": -5}`
   - 衰减：每 5 回合所有情绪值 ×0.9（缓慢回归中性）
   - StatePanel 用情绪雷达图可视化
2. **PC 心情/状态** — `Session.pc_mood_json` 跟踪 PC 当前情绪（疲惫/兴奋/沮丧/紧张...）
   - GM 通过 `<pc_mood>` 标签更新
   - 影响 GM 描写：心情不好时场景描写更阴郁
3. **NPC ↔ NPC 关系图** — 新表 `npc_relations`，加 `<npc_relation>` 标签
   - 关系类型：父女/恋人/对手/同事/师徒/盟友/仇敌/秘密
   - 简单力导向图可视化（vis-network 或 d3）
4. **GM 反应性引导** — system prompt 新一节"反应性原则"
   - 当 NPC 情绪某项 > 70：GM 必须让 NPC 主动表达
   - 当 PC 心情显著负面：场景描写注入对应基调
   - 当 NPC 关系网中两位发生冲突时，相关 NPC 都该有情绪波动
5. **端到端自动化测试** — 用 Playwright 起完整跑团流测一遍
   - 跑团页加载 → 发动作 → SSE 流式回流 → NPC dialog 打开 → choices 按钮点击
   - 防止 SSE/CRLF 那种事故再次出现而不被发现
6. **打包后冒烟测试** — CI 上对构建出的 .dmg 用 dmg-extractor 抽出 .app，跑 `./dzmm-backend --version` 之类的健康检查
   - 至少能跑了 launch + ping /health 才算 release green

预计 6 个任务，墙钟 ~40 分钟。

## v1.0 — 内容运营 + 分享 + 正式发布

**主题：** 从"个人玩具"到"小众工具"。

### Task 列表

1. **跑团结束生成故事书** — 一键导出整局为 Markdown / EPUB
   - 自动生成章节（按 Era 分）+ 收录关键事件
   - 包含玩家立绘 + NPC 关系图截图
   - 适合放小红书/Twitter 给朋友看
2. **世界观 / 角色 JSON 导入导出**
   - `GET /worlds/{id}/export` 返回完整设定 + 关联角色 JSON
   - `POST /worlds/import` 接受 JSON 创建
   - 用户可在社区论坛分享自己的世界
3. **内置模板库（8 套）** — 真正的内容运营
   - 已有：赛博朋克/大正怪谈/灵能/仙侠
   - 新增：克苏鲁/末世废土/校园悬疑/古代宫廷
   - 每套提供 1-2 个角色卡 + BGM 推荐
4. **AI 辅助世界生成器** — 一句话扩写完整世界
   - 用户输入"末世，丧尸，希望"
   - 调 GM 模型扩写出势力/禁忌/引子
   - 5 步可编辑流程
5. **代码签名（macOS Apple Developer + Windows EV）**
   - 去掉首次打开的 Gatekeeper / SmartScreen 警告
   - 需要付费证书（约 $400/年），先文档化方法
6. **macOS Universal Binary + Linux .deb/AppImage**
   - 让 Intel Mac 也能跑
   - Linux 用户能 `apt install`
7. **README 重写 + 视频演示** — 5 分钟演示视频上传 GitHub
8. **公开 v1.0 发布** — 放小红书/V2EX/Hacker News

预计 8 个任务，墙钟 ~1 小时。

## v1.1+（远期，玩家驱动）

按使用情况和反馈再排：

- 多人合作跑团（一个 GM + N 个 PC）—— 需要 auth + 实时同步 + 冲突解决
- TTS 让 GM "说话"（Edge TTS / Coqui）
- STT 语音输入
- Discord bot
- iOS / Android 原生客户端（Tauri Mobile）
- 自定义规则引擎（玩家自由定义骰子规则）
- 角色立绘 AI 生成（接 SD/Flux/NovelAI API）

## 跨版本工程基线

每轮版本必须保持：

- ✅ 全部 backend test pass
- ✅ frontend build clean (vue-tsc 无错误)
- ✅ Mac .dmg 能装能跑
- ✅ Windows .exe 能装能跑
- ✅ ChangeLog 中文记录
- ✅ 每个版本一个 git tag + GitHub Release

每轮版本应当尝试：

- 🎯 减少一个用户痛点
- 🎯 增加一项剧情深度
- 🎯 留下一个"哎，下一版可以怎样"的空间
