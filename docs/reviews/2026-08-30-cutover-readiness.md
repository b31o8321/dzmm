## 替换老版的硬门槛

1. macOS 安装包可见窗口并完成创建→游玩→结局→新 Run；当前 sidecar/API 闭环通过，GUI 自动化受系统权限限制。
2. Windows 原生 installer 安装、启动、模型配置和主旅程；当前构建与 smoke 通过，安装后 GUI 未验收。
3. Android release APK 本地模拟器冷启动/重开/失败恢复；当前冷启动、强制停止恢复和新世界→10 回合→结局→同世界新 Run 通过，真机与跨设备回读仍需补齐。
4. 旧版存档“不自动迁移”说明和主动导入路径已具备；归档 tag 与源码恢复演练已完成，运行时数据恢复与完整回滚演练仍待完成。
5. 正式代码、配置、包名、默认目录和文案不再混用 `DZMM Next`/`dzmm_vnext`。

未满足前，禁止将 vNext 直接合入 `main` 后删除旧版实现；可以继续在独立 worktree 迭代。当前玩家评分暂定 **95/100**。
