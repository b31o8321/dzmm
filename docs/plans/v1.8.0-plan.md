# v1.8.0 立项方案稿：主角跨局复用 + 小说素材出口（资产生态 P2 首批）

- 日期：2026-09-30 · 状态：已确认实施（开放问题按既定答案）
- 输入：asset-ecosystem-matrix.md P2（A4 hero 复用 / B5 剧情弧线 / D1 小说素材）

## 范围

1. **hero 跨局复用（A4 首切片）**：`CreateRunInput.hero_id`（可选）——同一世界内
   复用已有主角开启新局；安全默认 = 携带「过往旅程」快照（完成局数 + 各局结局
   标题），**不继承**属性/物品/关系（叙事完整性优先，继承策略留后续迭代）。
2. **小说素材导出 MVP（D1 首切片）**：`GET /runs/{id}/novel:export` —— 组装
   蒸馏产物（小传/台词/年表）+ 全量回合叙事为一份短篇素材 markdown（模板拼装，
   模型零参与）。

## 技术要点

- 复用入口：create_run 校验 hero_id 归属同一 world_version → 复用 hero id/name/
  profile → `hero.carried = {previous_runs, endings[]}`；hero 行不复制（同一聚合根）
- 出口：纯读组装，无新表；蒸馏缺失时对应小节约降级为回合叙事摘录

## 验收 gate

- 同 hero 开第二局：state.hero.id 相同、carried.previous_runs ≥ 1
- 有蒸馏产物的 run 导出 markdown 含「人物小传/正文素材/事件年表」三节

## 后续（不在本版）

- 继承策略深化（属性/关系/记忆）、D3 短剧分场、B4 关系网蒸馏
