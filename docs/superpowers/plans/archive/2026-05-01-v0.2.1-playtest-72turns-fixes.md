## 问题归类 + 优先级

### 🔴 P0 紧急（影响游玩，立即修）

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| **P0.1** | NPC 表 21 个垃圾名字（"里面"/"写着"/"个叫"/"塞巴" 等） | NER 阈值仍太松：2 字 + 频率 3 还能误抓常见动词搭配；PC 名字片段（塞巴/奥斯特）也被抓 | NER 强化：①最少 3 字（不再允许 2 字）②扩停用词表加 70+ 高频虚词 ③skip PC name 子串 ④常见结构「了/的/着/我/她/他/一」开头要求 ≥4 字 |
| **P0.2** | 30+ 回合后 GM 回复变短 / 71+ 回合开始胡乱对话 / **GM 输出泄漏 prompt 内容** | 长上下文超模型有效窗口 → 模型把 prompt few-shot 当成自己的输出抄回来 | ①摘要器更激进（每 10 回合压缩一次）②prompt 体积监控 + 自动 trim recent_messages ③few_shot 改成「不嵌入 markdown 标题」减少模型把它当输出格式 ④模型显示 token 计数 + 警告临界 |
| **P0.3** | NPC 卡片日志 vs 展示不一致（日志「艾琳娜」实际显示「院长」/ 日志「神秘人」显示「艾琳娜」）+ UI 似乎展示上一轮日志 | MessageEventsDialog 状态 stale —— `eventsDialogTurn / eventsDialogEvents` 在前端切换 turn 时没重置/同步 | 1. eventsDialog 关闭时清空 2. 打开时强制 fresh copy props.events 3. 测一下 reactive 是否在 turn array 元素上 |
| **P0.4** | 物品在角色卡页面没显示 | `inventory` ref 是从 `/state` 加载，可能玩家打开角色卡时 hydrate 还没完成 / 或事件应用没把 inventory_add 推到 ref | 检查 `applyStateChange` 是否处理 `inventory_add/inventory_remove`；onMounted 立即拉 state 而非 messages 后再拉 |
| **P0.5** | 「Unclosed tag <choices>」时不时出现 | v0.1.9 parser flush 已加但还是有报错 | 查 parser flush 是否在 caller 实际调用；前端 toast 用 ElMessage.warning 而不是 .error 减少视觉骚扰 |

### 🟠 P1 GM/Prompt 改进（影响体验，两轮内修）

| # | 问题 | 修复 |
