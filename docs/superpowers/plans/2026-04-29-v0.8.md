# v0.8 实施计划 — 编年史 + 目标系统 + 易用性

> 使用 superpowers:subagent-driven-development。

**主题：让世界记得发生过什么，让人物有目标。**

v0.7 已经把"角色档案+多维好感+剧情线"立起来了。v0.8 要让这些数据**汇聚成可追溯的故事**：
- 玩家能翻看完整编年史（按"卷/章"分组）
- PC 自己也有目标列表（不光是"完成 GM 给的任务"）
- 首次启动有引导，用户不用读 README
- 装好的应用能自动检测新版本

## Schema 预先准备（避免 4 个 agent 撞 db/models.py）

在派发 agent 之前，先一次性提交 schema：

```python
class Era(Base):
    __tablename__ = "eras"
    id: Mapped[int] = mapped_column(primary_key=True)
    session_id: Mapped[int] = mapped_column(ForeignKey("sessions.id"))
    name: Mapped[str] = mapped_column(String(120))
    started_turn: Mapped[int] = mapped_column(default=0)
    description: Mapped[str] = mapped_column(Text, default="")


class PCGoal(Base):
    __tablename__ = "pc_goals"
    id: Mapped[int] = mapped_column(primary_key=True)
    session_id: Mapped[int] = mapped_column(ForeignKey("sessions.id"))
    description: Mapped[str] = mapped_column(Text)
    priority: Mapped[str] = mapped_column(String(20), default="normal")  # high|normal|low
    status: Mapped[str] = mapped_column(String(20), default="active")  # active|completed|abandoned
    introduced_turn: Mapped[int] = mapped_column(default=0)
    completed_turn: Mapped[int | None] = mapped_column(nullable=True)
    completion_note: Mapped[str] = mapped_column(Text, default="")
```

Timeline 加 `era_id` 可空外键（v0.8 范围内可选——Chronicle 可以根据 turn 范围归到对应 era，不强求 FK）。
