**Tech Stack:** Vue 3 + Element Plus, FastAPI, SQLite via SQLAlchemy async. Tests: pytest-asyncio, vitest (frontend has no wizard tests currently — add backend tests only).

### Task 1: Backend — auto-retry wrapper + world_brief fallback

**Problem:** `generate_world_brief` uses `_parse_section(raw, "名字")` to extract the world name. If the LLM returns valid markdown but with slightly different header text (e.g. `## 世界名字` instead of `## 名字`), `_parse_section` returns `""` and the step 2 display shows nothing.

**Fix part 1:** Add a retry wrapper so transient format errors auto-retry up to 3 times.  
**Fix part 2:** In `generate_world_brief`, if `_parse_section` returns "" for all three fields, use the full `raw_md` as a fallback so the UI always has something to show.

import asyncio
from typing import TypeVar, Callable, Awaitable

_T = TypeVar("_T")


async def _with_retry(
    fn: Callable[[], Awaitable[_T]],
    max_attempts: int = 3,
) -> _T:
    """Call `fn()` up to `max_attempts` times, retrying on ValueError or
    json.JSONDecodeError (LLM format failures). Raises the last exception
    if all attempts fail."""
    last_err: Exception = RuntimeError("no attempts made")
    for _ in range(max_attempts):
        try:
            return await fn()
        except (ValueError, json.JSONDecodeError) as e:
            last_err = e
    raise last_err
```

async def generate_single_npc(
    world_md: str,
    character_md: str,
    hint: str,
    client: ModelClient,
) -> dict:
    """Generate one NPC based on a player-provided hint (archetype / role / name)."""
    from dzmm.prompts.wizard_npcs import build_npcs_messages  # reuse same prompt template

    hint_text = hint.strip() or "（根据世界观自由发挥）"
    messages = [
        {
            "role": "system",
            "content": (
                f"世界观：\n{world_md}\n\n主角：\n{character_md}\n\n"
                "你是世界观设计师。根据以下提示，生成**1个**主要 NPC，输出纯 JSON（无 markdown fence）。\n"
                "格式：{\"name\":\"...\",\"description\":\"...\",\"archetype\":\"...\",\"purpose\":\"...\"}"
            ),
        },
        {"role": "user", "content": f"NPC 提示：{hint_text}"},
    ]

    async def _attempt():
        raw = await _stream_text(client, messages, max_tokens=400)
        cleaned = _strip_fence(raw)
        try:
            npc = json.loads(cleaned)
        except json.JSONDecodeError as e:
            raise ValueError(f"single NPC JSON error: {e}; raw={raw[:200]!r}") from e
        if not isinstance(npc, dict) or not npc.get("name"):
            raise ValueError(f"invalid NPC shape: {npc!r}")
        return npc

    return await _with_retry(_attempt)
```

- [ ] **Step 1: Add persistence helpers at the top of `<script setup>` in `WizardView.vue`**

Read `WizardView.vue` first (lines 1-200). Then add after the `const step = ref(0)` declaration:

```typescript
const DRAFT_KEY = 'dzmm_wizard_draft'

function saveDraft() {
  try {
    localStorage.setItem(DRAFT_KEY, JSON.stringify({ step: step.value, state }))
  } catch { /* ignore quota errors */ }
}

function clearDraft() {
  localStorage.removeItem(DRAFT_KEY)
}

function loadDraft(): boolean {
  try {
    const raw = localStorage.getItem(DRAFT_KEY)
    if (!raw) return false
    const { step: savedStep, state: savedState } = JSON.parse(raw)
    Object.assign(state, savedState)
    step.value = savedStep
    return true
  } catch {
    clearDraft()
    return false
  }
}
```
