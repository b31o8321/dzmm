### Task A6: Streaming batch on SSE

**Files:** `backend/src/dzmm/api/routes_sessions.py`

**Why:** Each LLM token currently becomes one SSE event = one HTTP chunk + JSON serialize + UTF-8 + Vue reactive update + markdown re-render. On 50 tok/s, that's 50 reactive churns per second. Batching to ~20 chars or 50ms window cuts that to ~5 events/second with no perceived loss in smoothness.

- [ ] **Step 1:** in `event_stream()`, replace the NarrativeDelta emit branch with a buffer + flush helper. The full `take_turn` body should change from:

```python
            async for ev in run_turn(s, session_id, body.action, client):
                if isinstance(ev, NarrativeDelta):
                    yield {"event": "narrative",
                           "data": json.dumps({"text": ev.text}, ensure_ascii=False)}
                elif isinstance(ev, TagComplete):
                    yield {"event": "tag", ...}
                elif isinstance(ev, ParseError):
                    yield {"event": "parse_error", ...}
```

to:

```python
            import time as _time
            narrative_buf: list[str] = []
            last_flush = _time.monotonic()
            FLUSH_CHARS = 20
            FLUSH_INTERVAL = 0.05  # 50ms

            def _flush_narrative():
                if narrative_buf:
                    payload = "".join(narrative_buf)
                    narrative_buf.clear()
                    return {"event": "narrative",
                            "data": json.dumps({"text": payload}, ensure_ascii=False)}
                return None

            async for ev in run_turn(s, session_id, body.action, client):
                if isinstance(ev, NarrativeDelta):
                    narrative_buf.append(ev.text)
                    now = _time.monotonic()
                    total = sum(len(x) for x in narrative_buf)
                    if total >= FLUSH_CHARS or (now - last_flush) >= FLUSH_INTERVAL:
                        out = _flush_narrative()
                        if out:
                            yield out
                        last_flush = now
                elif isinstance(ev, TagComplete):
                    out = _flush_narrative()  # flush before non-narrative event
                    if out:
                        yield out
                    last_flush = _time.monotonic()
                    yield {"event": "tag",
                           "data": json.dumps({"name": ev.name, "attrs": ev.attrs,
                                               "content": ev.content},
                                              ensure_ascii=False)}
                elif isinstance(ev, ParseError):
                    out = _flush_narrative()
                    if out:
                        yield out
                    yield {"event": "parse_error",
                           "data": json.dumps({"message": ev.message},
                                              ensure_ascii=False)}

            out = _flush_narrative()
            if out:
                yield out

            await s.commit()
```

```python
@router.delete("/{session_id}/last_turn", status_code=204)
async def delete_last_turn(
    session_id: int, s: AsyncSession = Depends(get_session_dep)
):
    """Remove the most recent user/assistant message pair and decrement
    turn_count. Used by frontend's 'regenerate' / 'edit' actions.
    Note: char_state / NPC / plot_thread mutations from that turn are NOT
    rolled back — model rerolls usually overwrite them anyway."""
    sess = await s.get(GameSession, session_id)
    if sess is None:
        raise HTTPException(404, "session not found")
    if sess.turn_count <= 0:
        return  # nothing to delete

    rows = (await s.execute(
        select(MessageRow)
        .where(MessageRow.session_id == session_id)
        .order_by(MessageRow.id.desc())
        .limit(2)
    )).scalars().all()
    for r in rows:
        await s.delete(r)
    sess.turn_count = max(0, sess.turn_count - 1)
    await s.commit()
```
