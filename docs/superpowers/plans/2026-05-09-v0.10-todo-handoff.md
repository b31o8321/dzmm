## 架构速览（给下一个模型）

### 多 Agent 流（v0.10）

```
玩家 user_action
  ↓
run_turn (game.py) — settings.use_v10=True 时走 v0.10 路径
  ↓
orchestrator.run_turn_v10
  ├─ should_run_director? (triggers.py)
  │     ├─ True → run_director (LLM call) → 持久化到 agent_streams/messages
  │     └─ False → 复用上次 directive
  ├─ run_scene (LLM 流式) → 收集 narrative + npc_cue tags
  ├─ Scene 完成 → fan-out 仅 cued NPC（独立 SQLAlchemy session 并行 / 0 cue 时回退顺序）
  │     每个 NPC actor: build_npc_actor_messages(npc, history, plot_directive, scene_narrative,
  │                     user_action, scene_context, recent_dialogue, relationship_summary, cue_intent)
  └─ aggregate yields → SSE 给前端
  ↓
game.py: apply_tags + persist messages（含 snapshot_json） + agent_stream 压缩 + npc_initiative check
```

## 这次会话踩过的坑（避坑）

1. **PyInstaller 静默丢含语法错的模块** — seed_data.py 嵌套 `"..."` 引号让 Python 无法 parse；PyInstaller 静默跳过；运行时 ModuleNotFoundError。**对策**：打包前自检（P1 #4）。
2. **lazy import 不被 PyInstaller 静态分析捕获** — main.build_default_app 里 `from dzmm.seed_data import` 是函数内 import；collect_submodules 偶尔会漏。**对策**：spec 里显式 hiddenimports 列出关键模块（已加）。
3. **Wizard prompt 漏了 stats 字段** — 用户报告"角色状态尚未初始化"溯源发现 wizard_character.py 从来不让 LLM 产 base_stats；同时 wizard.finalize_wizard 也没建 CharState 行。**双重 bug**。修了，但**已有存档需要 backfill**（P1 #5）。
4. **subagent 并行时 SQLAlchemy AsyncSession 不安全** — 每个 NPC fan-out 用独立 session 解决（v0.10.2）。注意：commit 主 session 必须发生在 fan-out 之前，否则 SQLite 写锁会冲突（subagent 实际跑出来发现的）。
5. **subagent 并行 commit git index** — 多个 subagent 同时 `git add` 不同文件后 `git commit` 会互相吃 staged 文件。**对策**：每个 subagent 用 `git commit -m "..." -- file1 file2 ...`（path-limited），保证只 commit 自己的文件。
6. **WIP 跨 session 累积未 commit** — 早期会话的实现完成但没 commit，后面被并发修改打架。**对策**：每个明确"完成"的 task 立刻 commit。
