# v0.2.5 Gameplay Quality Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 4 core gameplay quality issues: (1) NER garbage NPC names by deleting the fallback entirely, (2) screenplay main events never completing (force-advance too weak), (3) dumb static quick-action buttons replaced with context-aware suggestions via a parallel sub-agent, (4) per-session model switching.

**Architecture:** NER fallback is pure Python — delete the function and the call site. Screenplay force-advance is a prompt injection in `service/game.py` — lower threshold and make the directive much more explicit. Contextual actions use a new `POST /sessions/{id}/suggest_actions` endpoint called in parallel with the GM turn start (not blocking). Model switching is a `PATCH /sessions/{id}` endpoint.

**Tech Stack:** FastAPI async, SQLAlchemy 2.0, Vue 3, Element Plus. Tests: pytest-asyncio.

```python
# backend/src/dzmm/api/routes_sessions/suggest.py
"""POST /sessions/{id}/suggest_actions — generate 3 contextual action hints.

Called by the frontend immediately after a GM turn completes. Uses a small,
fast LLM call with a minimal prompt. Runs in parallel with user reading the
GM response — zero added wait time."""
from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel
from sqlalchemy.ext.asyncio import AsyncSession

from dzmm.api.routes_sessions._common import build_client, get_session_dep
from dzmm.db.models import ModelConfig, Session as GameSession
from dzmm.models.client import GenerationParams

router = APIRouter(prefix="/sessions", tags=["sessions"])


class SuggestRequest(BaseModel):
    narrative: str       # last GM narrative text (max ~400 chars)
    goals: list[str] = []  # active PC goal descriptions


@router.post("/{session_id}/suggest_actions")
async def suggest_actions(
    session_id: int,
    body: SuggestRequest,
    s: AsyncSession = Depends(get_session_dep),
):
    sess = await s.get(GameSession, session_id)
    if sess is None:
        raise HTTPException(404, "session not found")

    cfg = await s.get(ModelConfig, sess.gm_model_config_id)
    if cfg is None:
        raise HTTPException(422, "model config not found")

    client = build_client(cfg)
    narrative_snippet = body.narrative[:400] if body.narrative else ""
    goals_text = "、".join(body.goals[:3]) if body.goals else "无"

    messages = [
        {
            "role": "system",
            "content": (
                "你是 TRPG 助手，根据当前场景和玩家目标，给出 3 个简短的行动建议。\n"
                "每条建议不超过 12 个汉字，直接是玩家可以做的动作。\n"
                "只输出 3 行，每行一个建议，不加序号不加解释。"
            ),
        },
        {
            "role": "user",
            "content": f"当前场景：{narrative_snippet}\n当前目标：{goals_text}",
        },
    ]

    chunks: list[str] = []
    try:
        async for ch in client.stream(
            messages, GenerationParams(max_tokens=80, temperature=0.8)
        ):
            if ch.delta:
                chunks.append(ch.delta)
    except Exception:
        return {"suggestions": []}

    raw = "".join(chunks).strip()
    suggestions = [line.strip() for line in raw.splitlines() if line.strip()][:3]
    return {"suggestions": suggestions}
```
