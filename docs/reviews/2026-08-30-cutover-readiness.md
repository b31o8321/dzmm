## 替换老版的硬门槛

1. macOS 安装包可见窗口并完成创建→游玩→结局→新 Run。
2. Windows 原生 installer 安装、启动、模型配置和主旅程。
3. Android release APK 本地模拟器冷启动/重开/失败恢复；真机证据若作为发布声明仍需单独补齐。
4. 旧版存档迁移或明确不迁移说明可被玩家理解，并有可回滚归档 tag。
5. 正式代码、配置、包名、默认目录和文案不再混用 `DZMM Next`/`dzmm_vnext`。

未满足前，禁止将 vNext 直接合入 `main` 后删除旧版实现；可以继续在独立 worktree 迭代。
